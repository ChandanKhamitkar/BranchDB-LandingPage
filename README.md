# BranchDB

[**BranchDB**](https://github.com/ChandanKhamitkar/BranchDB) is a lightweight, high-performance key-value database, built in C++. Designed for simplicity, speed, and minimal footprint.

---

## Features

- **Simple key-value storage** — set and get operations with minimal API surface.
- **High performance** — optimized for speed and low latency.
- **Minimal footprint** — easy to compile and integrate into your C++ projects.

---

## Why BranchDB?

BranchDB cuts the clutter. Pure C++, lean API, and blazing fast—designed to be embedded, not bloated.
